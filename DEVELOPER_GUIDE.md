## Частые задачи и как их формулировать

### Добавить новый дизайн виджета

#### Вариант 1: Создание темы с нуля по референсу

**Когда использовать:** Вы нашли виджет на другом сайте и хотите такой же стиль.

**Шаг 1:** Подготовьте референс
- Сделайте скриншот виджета (желательно в разных состояниях: закрытый, открытый, hover)
- Или дайте ссылку на сайт

**Шаг 2:** Добавьте файл в проект
- Создайте папку (если её нет): `C:\Project\Floqly\references\widgets\`
- Положите скриншот туда
- Назовите файл понятно: `intercom-style.png`, `drift-widget.png` и т.д.

**Шаг 3:** Напишите разработчику по этому шаблону:
```
Хочу создать новую тему виджета с нуля по референсу.

Референс: references/widgets/intercom-style.png
(или ссылка: https://www.intercom.com)

Название новой темы: "Intercom Style"

Что точно нужно взять из референса:
- Форма виджета (круглая/квадратная/другая)
- Цветовая схема (синий градиент)
- Тени и размытие (если есть)
- Анимации (как виджет появляется, раскрывается)

Что изменить под нас:
- Наш основной цвет: #6366F1 (вместо их синего)
- Размер чуть больше (их 56px, наш 64px)

Дополнительно:
- Нужна светлая и тёмная версия темы
```

**Что сделает разработчик:**
1. Изучит референс детально (цвета, тени, формы, анимации)
2. Создаст новый файл темы: `src/components/widgets/themes/intercomStyle.ts`
3. Реализует дизайн с учётом ваших изменений
4. Покажет вам preview (скриншот или запустит dev-сервер)
5. Внесёт правки если нужно
6. Добавит тему в конструктор

**Важно указать:**
- **Что именно нравится** в референсе (форма, цвета, анимации, тени)
- **Что хотите изменить** (цвета, размеры, поведение)
- **Нужна ли тёмная версия** темы (обычно да)

#### Вариант 2: Изменение существующей темы

**Когда использовать:** У вас уже есть тема (например Glassmorphism), но хотите что-то подправить.

**Шаблон для разработчика:**
```
Хочу изменить существующую тему виджета.

Тема: Glassmorphism

Что изменить:
1. Увеличить размытие фона с 10px до 20px (сейчас слабо видно эффект стекла)
2. Сделать границу виджета более заметной: 2px вместо 1px
3. Цвет границы: голубой (#3B82F6) вместо белого
4. Добавить лёгкую тень снизу для объёма

Референс (опционально): references/widgets/desired-effect.png
(если есть пример того, как должно выглядеть)
```

**Что сделает разработчик:**
1. Откроет файл темы: `src/components/widgets/themes/glassmorphism.ts`
2. Изменит параметры:
   ```typescript
   blur: '20px',           // было 10px
   border: '2px solid #3B82F6',  // было 1px solid white
   boxShadow: '0 8px 16px rgba(0,0,0,0.1)'  // добавил тень
   ```
3. Покажет результат (до/после)
4. Если нужно - внесёт дополнительные правки

**Важно указать:**
- **Название темы** которую меняете
- **Конкретные параметры** (размеры, цвета в пикселях/hex)
- **Почему меняете** (опционально, но помогает понять цель)

#### Вариант 3: Видео
Если нужно показать анимацию:
1. Запишите видео экрана (Win + G → Capture)
2. Или найдите видео на YouTube
3. Укажите таймкод: "С 0:15 до 0:20"

### Что описать про референс

Когда показываете референс, напишите:
- **Что именно нравится:** "Форма виджета", "Анимация появления", "Цветовая схема"
- **Что хотите изменить:** "Но иконку заменить на нашу", "Сделать чуть меньше"
- **Для какой темы:** "Это для темы Glassmorphism" или "Новая тема"

**Пример:**
```
Референс: references/widgets/drift-widget.png

Что нравится:
- Ассиметричная форма виджета (не круглая)
- Градиент от синего к фиолетовому
- Pulse анимация (виджет "дышит")

Что изменить:
- Наши цвета вместо их (наш фиолетовый #6366F1)
- Добавить небольшую тень

Это будет новая тема: "Gradient Pulse"
```

## Частые вопросы

### Как добавить виджет на мой сайт?

**Ответ:**
1. Откройте конструктор виджетов: `https://floqly.ru/widget-builder`
2. Настройте виджет (дизайн, цвета, контакты)
3. Нажмите кнопку "Скопировать код"
4. Откройте HTML файл вашего сайта
5. Найдите закрывающий тег `</body>`
6. Вставьте скопированный код **перед** `</body>`
7. Сохраните файл
8. Обновите сайт в браузере - виджет появится

### Виджет не появляется на сайте, что делать?

**Частые причины:**
1. **Код вставлен неправильно** → Проверьте что код перед `</body>`
2. **Кэш браузера** → Нажмите Ctrl + F5 для жёсткой перезагрузки
3. **Конфликт с другими скриптами** → Напишите разработчику

**Что написать разработчику:**
```
Виджет не появляется на сайте.

Мой сайт: https://example.com
Куда вставил код: [скриншот или описание]
Ошибки в консоли: [нажмите F12 → вкладка Console → скриншот]
```

### Как изменить виджет после установки?

**Ответ:**
Есть 2 варианта:

**Вариант 1: Через конструктор (публичная страница)**
1. Внесите изменения в конструкторе
2. Скопируйте новый код
3. Замените старый код на сайте новым

**Вариант 2: Через личный кабинет (когда будет готов)**
1. Войдите в личный кабинет
2. Откройте настройки виджета
3. Внесите изменения
4. Нажмите "Сохранить"
5. Виджет обновится автоматически (не нужно менять код на сайте)

### Сколько виджетов можно создать?

**Ответ:**
- **Сейчас (без личного кабинета):** Сколько угодно, но они не сохраняются
- **С личным кабинетом:** Зависит от тарифа (обычно не ограничено)

### Можно ли использовать один виджет на нескольких сайтах?

**Ответ:**
Да, можно. Просто вставьте тот же код на все сайты.

Но **рекомендуется** создать отдельный виджет для каждого сайта, чтобы:
- Подобрать цвета под дизайн каждого сайта
- Отдельно отслеживать статистику
- Разные контакты для разных проектов

### Как сделать виджет адаптивным (для мобильных)?

**Ответ:**
Виджет автоматически адаптируется под размер экрана. Но вы можете настроить:
- **Размер на мобильных:** В конструкторе отдельные настройки для мобильных (будет добавлено)
- **Позицию:** На мобильных виджет лучше размещать внизу справа

Если виджет плохо выглядит на мобильных - напишите разработчику с скриншотом.

## Полезные инструменты

### Инспектор браузера (для поиска ошибок)
1. Откройте ваш сайт
2. Нажмите F12 (откроется панель разработчика)
3. Вкладка **Console** → здесь ошибки скриптов
4. Вкладка **Network** → здесь ошибки загрузки файлов
5. Сделайте скриншот и отправьте разработчику

### Как сделать скриншот
- **Windows:** Win + Shift + S
- **Mac:** Cmd + Shift + 4
- Или используйте инструмент "Ножницы" (встроенный в Windows)

### Как записать видео экрана
- **Windows:** Win + G (Xbox Game Bar)
- **Mac:** Cmd + Shift + 5
- Или используйте: OBS Studio, Loom, ShareX
