**Он НЕ должен трогать**:

После завершения Antigravity создаст файл `ANTIGRAVITY_CHANGES.md` с:

## ⚙️ Команды для работы

### Локальная разработка
```bash
# Установка зависимостей
npm install

# Запуск dev сервера
npm run dev

# Проверка типов
npm run type-check

# Линтинг
npm run lint

# Сборка для production
npm run build
```

### Git workflow
```bash
# Получить последние изменения
git pull origin Floqly

# Добавить изменения
git add .

# Коммит
git commit -m "Описание изменений"

# Запушить
git push origin Floqly
```

### Docker (для деплоя)
```bash
# Сборка образа
docker-compose build

# Запуск контейнера
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down
```
