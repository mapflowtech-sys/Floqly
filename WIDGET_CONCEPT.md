# Концепция виджетов Floqly

**Дата создания:** 2026-01-12

---

## Общая концепция

### Два типа виджетов

1. **Обычный виджет (бесплатный)**
   - Классический виджет для связи с владельцем сайта
   - Иконки соцсетей и мессенджеров (Telegram, WhatsApp, VK, Email, Телефон, Viber, Instagram)
   - Клиент использует его бесплатно
   - Настраивается через конструктор

2. **Умный виджет (платный)**
   - Тот же визуальный дизайн что и обычный
   - + Проактивные сообщения посетителям
   - + AI-диалог (обучен на данных сайта клиента)
   - + Возможность перехватить управление оператором
   - Апгрейд от обычного виджета

### Ключевой принцип дизайна

**Плавный переход:** Клиент начинает с бесплатного обычного виджета, привыкает к нему, потом upgrade на умный виджет выглядит естественно (тот же дизайн + новые возможности).

---

## UX/UI принципы виджетов

### Главное правило
**Не отвлекать и не раздражать посетителя сайта!**

- Анимации только премиальные и красивые
- Возможность отключить анимации
- Ненавязчивое поведение
- Быстрая работа (минимальный вес JS)

### Качество превыше всего
- Лучший UX/UI среди всех виджетов на рынке
- Внимание к деталям
- Тестирование на реальных пользователях

## Архитектура разделения ответственности

### Наша зона ответственности (Floqly платформа)
- **Весь UI/UX виджета** (дизайн, анимации, формы)
- Конструктор виджетов
- Генерация embed кода
- Хостинг JS-скрипта виджета
- Личный кабинет для настройки

### Зона ответственности партнёра
- **Только AI-логика** (понимание контекста, ответы)
- Парсинг сайта клиента
- Обучение на данных клиента
- WebSocket для real-time чатов
- API для управления виджетом

### Взаимодействие
- Наш виджет (UI) → API партнёра (логика)
- Партнёр подключается к нашему дизайну через API
- Мы контролируем визуальную часть полностью

## Дизайны виджетов

### Стили (5 базовых + возможность добавления новых)

#### 1. Glassmorphism
- **Светлая тема:** Полупрозрачный белый, backdrop-filter blur
- **Тёмная тема:** Полупрозрачный тёмный, backdrop-filter blur
- Характеристики:
  - Полупрозрачность: `rgba(255, 255, 255, 0.1)` или `rgba(0, 0, 0, 0.1)`
  - Blur: `backdrop-filter: blur(10px)`
  - Border: `1px solid rgba(255, 255, 255, 0.2)`
  - Тени: мягкие, размытые

#### 2. Neomorphism
- **Светлая тема:** Выпуклые/вдавленные элементы, мягкие тени
- **Тёмная тема:** Тот же принцип, но с тёмным фоном
- Характеристики:
  - Box-shadow: двойная тень (светлая + тёмная)
  - Почти плоский, но с объёмом
  - Мягкие скругления
  - Минимум контрастности

#### 3. Liquid Glass
- Эффект жидкого стекла
- Плавные градиенты
- Текучие формы
- Анимированные блики (опционально)

#### 4-5. Референсные дизайны
- Будут добавлены на основе референсов клиента
- Система должна позволять легко добавлять новые темы

### Формы виджета

**3 варианта форм:**

1. **Круг (сфера)**
   - Классический круглый bubble
   - Размеры: 56px, 64px, 72px (small, medium, large)

2. **Квадрат со скруглением**
   - Стиль Google Material Design
   - Border-radius: 16px-20px
   - Размеры: 56×56px, 64×64px, 72×72px

3. **Ассиметричная форма**
   - Органическая форма (blob shape)
   - CSS border-radius: сложные значения
   - Или SVG path для кастомной формы

### Параметры кастомизации

#### Обязательные параметры:
- **Дизайн-тема:** Glassmorphism / Neomorphism / Liquid Glass / Custom
- **Адаптация под тему сайта:** Светлая / Тёмная / Авто
- **Форма:** Круг / Квадрат / Ассиметрия
- **Размер:** Small / Medium / Large
- **Позиция:**
  - Горизонталь: Left / Right
  - Вертикаль: Top / Bottom
  - Отступы от края (в px)
- **Цвета:**
  - Основной цвет (primary color)
  - Цвет иконок/текста
  - Цвет фона (если не прозрачный)
- **Анимации:**
  - Тип появления: Fade / Slide / Scale / None
  - "Дыхание" bubble: Pulse / None
  - Скорость анимации: Slow / Medium / Fast
  - Включить/выключить анимации

#### Специфичные для обычного виджета:
- **Направление раскрытия иконок:**
  - Сверху виджета (вертикальный стек)
  - Слева от виджета (горизонтальный ряд)
  - Вокруг виджета (радиальное меню, круг)
- **Список контактов для показа:**
  - Telegram (ссылка)
  - WhatsApp (номер)
  - VK (ссылка)
  - Email (адрес)
  - Телефон (номер)
  - Viber (номер)
  - Instagram (ссылка)

#### Специфичные для умного виджета:
- **Проактивное сообщение:**
  - Как показывать: Облачко слева / Трансформация виджета / Другое (экспериментально)
  - Текст сообщения (задаётся партнёром через API)
  - Триггеры показа (настраиваются партнёром)
- **Окно чата с AI:**
  - Размер: 380×600px (десктоп), fullscreen (мобильный)
  - Стиль окна: соответствует теме виджета
  - Показывать ли иконки обычных контактов сверху (выпадающее меню)

## Поведение виджетов

### Обычный виджет

**Состояния:**

1. **Collapsed (свёрнут):**
   - Виджет-bubble в углу экрана
   - Иконка внутри (например, сообщение или логотип)
   - Анимация "дыхания" (опционально)

2. **Expanded (развёрнут):**
   - Клик на bubble → раскрываются иконки контактов
   - 3 варианта раскрытия:
     - **Сверху:** Иконки выстраиваются вертикально над bubble
     - **Слева:** Иконки выстраиваются горизонтально слева от bubble
     - **Вокруг:** Иконки располагаются по кругу вокруг bubble (радиальное меню)
   - Клик на иконку → действие (открыть Telegram, позвонить, написать email и т.д.)
   - Клик вне виджета или на крестик → collapse обратно

**Анимации:**
- Появление виджета при загрузке страницы
- Раскрытие иконок (stagger animation - по очереди)
- Hover эффекты на иконках
- Пульсация bubble (опционально)

---

### Умный виджет

**Состояния:**

1. **Idle (в покое):**
   - Выглядит как обычный виджет
   - Ждёт триггера от AI

2. **Proactive message (проактивное сообщение):**
   - AI решает показать сообщение посетителю
   - **Варианты отображения (нужно экспериментировать!):**
     - Облачко слева от bubble (как в комиксах)
     - Трансформация bubble в мини-окно с текстом
     - Всплывающее окошко рядом с виджетом
   - **Главное:** Не должно раздражать или отвлекать!
   - Анимация появления: плавная, премиальная
   - Пользователь может:
     - Кликнуть → открыть чат
     - Закрыть сообщение (крестик)
     - Игнорировать (сообщение исчезнет через N секунд)

3. **Chat opened (чат открыт):**
   - Клик на bubble или на проактивное сообщение → открывается окно чата
   - **Окно чата:**
     - Размер: 380×600px (desktop), fullscreen (mobile)
     - Дизайн соответствует теме виджета
     - **Шапка окна:**
       - Название (например, "Ассистент сайта")
       - Иконка выпадающего меню (открывает обычные контакты)
       - Кнопка закрытия
     - **Тело окна:**
       - История сообщений
       - AI отвечает в real-time
       - Typing indicator ("печатает...")
     - **Подвал окна:**
       - Поле ввода текста
       - Кнопка отправки
       - Опционально: прикрепление файлов (для будущего)
   - **Выпадающее меню контактов (в шапке):**
     - Клик на иконку → dropdown с обычными контактами
     - Telegram, WhatsApp, VK, Email, Телефон и т.д.
     - На случай если пользователь хочет связаться напрямую

4. **Operator takeover (оператор взял управление):**
   - Владелец сайта видит новый чат в дашборде
   - Кликает "Взять управление"
   - Теперь отвечает человек, а не AI
   - В окне чата посетитель видит: "Сейчас с вами общается оператор"

**Анимации:**
- Появление проактивного сообщения (эксперименты!)
- Трансформация bubble → окно чата (smooth transition)
- Typing indicator AI
- Отправка сообщения (плавное появление в истории)

## Адаптивность и мобильные устройства

### Критически важно: Виджет НЕ должен мешать на мобильных!

**Главный принцип:** На мобильных устройствах виджет должен быть максимально ненавязчивым и не закрывать контент сайта.

### Адаптивные размеры виджета

**Desktop (>768px):**
- Small: 56×56px
- Medium: 64×64px
- Large: 72×72px

**Mobile (<768px):**
- Small: 48×48px (уменьшаем на 8px)
- Medium: 56×56px (уменьшаем на 8px)
- Large: 64×64px (уменьшаем на 8px)

**Вывод:** На мобильных виджет автоматически становится чуть меньше, чтобы не занимать много места

### Позиционирование на мобильных

**Desktop:**
- Отступ по умолчанию: 24px от краёв
- Можно настроить: от 16px до 48px

**Mobile:**
- Отступ по умолчанию: 16px от краёв (меньше чем на desktop)
- Фиксированно: 12-20px (не настраивается, чтобы не вылезало за экран)
- **Всегда внизу:** На мобильных виджет ВСЕГДА позиционируется внизу (bottom), независимо от настроек desktop

**Почему внизу на мобильных:**
- Большой палец удобно достаёт (thumb-friendly zone)
- Не закрывает важный контент сверху
- Привычное место для мобильных чатов

### Поведение окна чата на мобильных

**Desktop:**
- Окно чата: 380×600px
- Открывается рядом с виджетом
- Можно перемещать (опционально)

**Mobile:**
- Окно чата: **Fullscreen** (на весь экран)
- Открывается как отдельная страница
- Кнопка "Назад" в шапке для закрытия
- Виджет-bubble скрывается когда чат открыт

### Адаптивные иконки контактов

**Desktop:**
- Размер иконок: 24-32px (зависит от размера виджета)
- Расстояние между иконками: 12px
- Можно показать до 6 иконок

**Mobile:**
- Размер иконок: 20-28px (чуть меньше)
- Расстояние: 8px (компактнее)
- Максимум 4 иконки (чтобы не растягивать)
- Touch target: минимум 44×44px (Apple HIG стандарт)

### Анимации на мобильных

**Desktop:**
- Все анимации работают полностью
- Плавные transitions
- Hover эффекты

**Mobile:**
- Упрощённые анимации (меньше blur, меньше shadows)
- Быстрее (200ms вместо 300ms)
- Нет hover эффектов (только tap)
- Reduce motion: если в системе включено "уменьшить движение" - минимальные анимации

### Performance на мобильных

**Критично:**
- Виджет должен загружаться быстро даже на 3G
- Lazy loading: виджет загружается после основного контента сайта
- Минимальный JavaScript (<50KB gzip)
- CSS оптимизирован (нет тяжёлых фильтров на слабых устройствах)

**Техники оптимизации:**
- На слабых устройствах: отключать backdrop-filter blur (тяжёлый эффект)
- Детект производительности: `window.navigator.hardwareConcurrency < 4` → упрощённая версия
- IntersectionObserver: анимации только когда виджет в viewport

### Проверка адаптивности (обязательно тестировать)

**Устройства для теста:**
- iPhone SE (маленький экран, 375×667px)
- iPhone 12/13 (стандарт, 390×844px)
- iPad (планшет, 768×1024px)
- Android (Samsung, различные разрешения)

**Браузеры:**
- iOS Safari (критично! самые строгие правила)
- Chrome Mobile
- Yandex Browser Mobile (для РФ)

### Edge cases (крайние случаи)

**Ландшафтная ориентация (landscape):**
- Виджет остаётся в углу
- Не должен мешать просмотру широкого контента
- Иконки контактов: горизонтальное расположение предпочтительнее

**Маленькие экраны (<320px):**
- Минимальный размер виджета: 40×40px
- Максимум 2-3 иконки контактов
- Текст в чате: 14px минимум

**Клавиатура открыта:**
- Виджет НЕ должен скрываться под клавиатурой
- Окно чата: скроллится чтобы поле ввода было видно
- iOS: использовать `visualViewport` API для правильного позиционирования

### Vanilla JS скрипты для клиентов

**Обычный виджет:**
```html
<!-- Клиент вставляет на свой сайт -->
<script
  src="https://floqly.ru/widgets/ordinary-widget.js"
  data-widget-id="wid_abc123"
  async
></script>
```

**Умный виджет:**
```html
<!-- Апгрейд: меняется только src -->
<script
  src="https://floqly.ru/widgets/smart-widget.js"
  data-widget-id="wid_abc123"
  async
></script>
```

**Требования к скриптам:**
- Минимальный вес (<50KB gzip, если возможно)
- Shadow DOM для изоляции стилей
- Не конфликтует с клиентским сайтом
- Поддержка IE11 не нужна (современные браузеры)
- Lazy loading (не блокирует загрузку страницы)

## База данных (Supabase)

### Таблица: widget_configs

```sql
CREATE TABLE widget_configs (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  user_id UUID REFERENCES auth.users(id),
  widget_type TEXT CHECK (widget_type IN ('ordinary', 'smart')),

  -- Общие настройки
  theme TEXT NOT NULL,                    -- 'glassmorphism', 'neomorphism', 'liquidGlass', 'custom1', 'custom2'
  theme_mode TEXT,                        -- 'light', 'dark', 'auto'
  shape TEXT NOT NULL,                    -- 'circle', 'square', 'asymmetric'
  size TEXT NOT NULL,                     -- 'small', 'medium', 'large'
  position_horizontal TEXT NOT NULL,      -- 'left', 'right'
  position_vertical TEXT NOT NULL,        -- 'top', 'bottom'
  offset_x INTEGER DEFAULT 24,            -- Отступ от края по X
  offset_y INTEGER DEFAULT 24,            -- Отступ от края по Y

  primary_color TEXT,                     -- Hex цвет
  text_color TEXT,                        -- Hex цвет
  background_color TEXT,                  -- Hex цвет (если не прозрачный)

  -- Анимации
  animation_enabled BOOLEAN DEFAULT true,
  animation_entrance TEXT,                -- 'fade', 'slide', 'scale', 'none'
  animation_pulse BOOLEAN DEFAULT false,  -- Pulse анимация bubble
  animation_speed TEXT DEFAULT 'medium',  -- 'slow', 'medium', 'fast'

  -- Специфично для обычного виджета
  contacts_expand_direction TEXT,         -- 'top', 'left', 'radial'
  contacts JSONB,                         -- { telegram: 'https://t.me/...', whatsapp: '+7...', ... }

  -- Специфично для умного виджета
  proactive_message_style TEXT,           -- 'bubble-left', 'transform', 'popup'
  show_contacts_in_chat BOOLEAN DEFAULT true,

  -- Мета
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW(),
  is_active BOOLEAN DEFAULT true
);
```

**URL:** `/widget-builder` (публичная страница)

**Функционал:**

## Важные заметки

### Для разработчика (Claude)

**Как добавить новую тему виджета:**
1. Создать новый файл в `src/components/widgets/themes/newTheme.ts`
2. Экспортировать объект типа `WidgetTheme`
3. Добавить тему в `src/components/widgets/themes/index.ts`
4. Тема автоматически появится в конструкторе

**Как переделать обычный виджет в умный:**
1. Изменить `widget_type` в БД: `'ordinary'` → `'smart'`
2. Фронтенд автоматически покажет возможности умного виджета
3. Embed код меняется: `ordinary-widget.js` → `smart-widget.js`

**Структура проекта:**
- React компоненты для preview и дашборда
- Vanilla JS скрипты для production (сайты клиентов)
- Общие темы и стили переиспользуются в обоих

### Для клиента (владельца проекта)

**Как добавить новый дизайн виджета:**
1. Подготовить референс (скриншот или ссылку на сайт)
2. Добавить файл в папку `references/widgets/` проекта
3. Написать разработчику:
   ```
   Привет! Хочу добавить новый дизайн виджета.
   Референс: references/widgets/example.png
   Название: "Modern Minimalist"
   Особенности: [описать что нравится в дизайне]
   ```
4. Разработчик создаст новую тему на основе референса

**Как переделать обычный виджет в умный (для клиента):**
1. В личном кабинете открыть виджет
2. Нажать кнопку "Апгрейд до умного виджета"
3. Настроить дополнительные параметры (проактивные сообщения)
4. Сохранить
5. Обновить код на сайте (или автоматически если используется динамическая загрузка)

**Инструкция по установке виджета:**
1. Скопировать код из конструктора
2. Вставить код перед закрывающим тегом `</body>` на сайте
3. Сохранить изменения
4. Виджет появится на сайте автоматически
