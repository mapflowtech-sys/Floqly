# 📋 Бриф для Google Antigravity - Создание главной страницы Floqly

## 🎯 Задача

Создать **только главную страницу (Hero-секция)** для проекта Floqly в стиле минималистичного референса HAS.WORKS.

**ВАЖНО**: Не изменяй ничего кроме компонентов главной страницы! Все остальные части проекта будут разрабатываться в Claude Code.

---

## 📖 О проекте Floqly

**Floqly** — B2B SaaS платформа для умного AI-виджета, который повышает конверсию сайтов клиентов.

**Целевая аудитория**: Малый и средний бизнес (владельцы сайтов)

**Ключевое УТП**: Виджет анализирует поведение посетителей и вступает в диалог в нужный момент, превращая интерес в продажи автоматически.

## 🛠 Технологический стек (СТРОГО ПРИДЕРЖИВАТЬСЯ!)

### Обязательные технологии
- **Next.js 15.1.3+** (App Router, НЕ Pages Router!)
- **React 19.0.0**
- **TypeScript** (strict mode)
- **Tailwind CSS 3.4+**

### Уже установленные библиотеки (можешь использовать)
- `framer-motion` (для анимаций)
- `gsap` (для сложных анимаций)
- `clsx` и `tailwind-merge` (для условных классов)
- `lucide-react` (для иконок)

### Шрифты (УЖЕ НАСТРОЕНЫ!)
- **Cormorant Garamond** - для заголовков (`font-heading`)
- **IBM Plex Mono** - для UI и навигации (`font-mono`)
- **Caveat** - для рукописной надписи (`font-handwriting`)

**Используй CSS классы**: `.font-heading`, `.font-mono`, `.font-handwriting`

### Цветовая схема (УЖЕ НАСТРОЕНА!)
```css
--background: теплый off-white (#F5F5F0)
--foreground: почти черный (#1A1A1A)
```

## 🎨 Дизайн-требования (КРИТИЧНО!)

### Референс
**HAS.WORKS** (https://has.work) - изучи этот сайт внимательно!

### Ключевые принципы дизайна

#### ✅ ЧТО НУЖНО ДЕЛАТЬ:
- **Минимализм**: Много белого пространства, мало элементов
- **Крупная типографика**: Огромный заголовок как в референсе
- **Сдержанные цвета**: 2-3 основных цвета максимум
- **Плотный tracking**: Буквы в заголовке близко друг к другу (tracking-tight или отрицательный)
- **Тонкие шрифты**: font-light для заголовков
- **Простые анимации**: Плавные, едва заметные (200-300ms)
- **Функциональность**: Каждый элемент имеет цель

#### ❌ ЧЕГО ИЗБЕГАТЬ (Анти-паттерны AI-дизайна):
- Градиенты везде
- Чрезмерный blur
- Слишком округлые углы (>16px)
- Неоновые цвета
- Хаотичные анимации
- Бессмысленные 3D эффекты
- Типичные AI-фразы ("cutting-edge", "revolutionary")

### Структура главной страницы

#### Header (Верхняя часть)
```
[FLOQLY]  ---------------  [ГЛАВНАЯ]  [ИНСТРУМЕНТЫ]  [КОНТАКТЫ]  ---------------  [ВОЙТИ]
```

**Требования к Header**:
- Фиксированный (sticky), но без видимых границ
- Логотип "FLOQLY" слева - моноширинный шрифт (`.font-mono`)
- Навигация по центру - маленький размер (text-[10px])
- "Войти" справа
- Фон сливается с основным фоном страницы
- Всё в uppercase

#### Hero-секция (Центральная часть)

**Структура сверху вниз**:

1. **Рукописная надпись** (слева от виджета)
   - Текст: "Логика подождёт"
   - Шрифт: `.font-handwriting`
   - Наклон: `-rotate-[12deg]` до `-rotate-[15deg]`
   - Прозрачность: `text-foreground/60`
   - Размер: `text-lg md:text-xl`

2. **Виджет/Сфера** (центр, над заголовком)
   - Простая круглая форма
   - Размер: `w-56 h-56 md:w-72 md:h-72 lg:w-80 lg:h-80`
   - Градиент: `bg-gradient-to-br from-foreground/12 to-foreground/20`
   - Тень: сильная, мягкая (`shadow-2xl` или кастомная)
   - Без сложных анимаций (максимум - лёгкое пульсирование)

3. **Заголовок** (огромный, главный элемент)
   ```
   Виджет, который
   знает, чего хочет
   клиент.
   ```
   - Шрифт: `.font-heading`
   - Размер: `text-5xl md:text-7xl lg:text-8xl` (НЕ больше!)
   - Вес: `font-light` (тонкий шрифт как в референсе)
   - Leading: `leading-[0.92]` (плотный междустрочный интервал)
   - Tracking: `tracking-[-0.02em]` (отрицательный, буквы близко)
   - Отступ снизу: `mb-6 md:mb-8` (НЕБОЛЬШОЙ!)

4. **Подзаголовок** (маленький текст, близко к заголовку)
   - Текст: "Floqly анализирует поведение посетителей и вступает в диалог в нужный момент. Превращайте интерес в продажи автоматически."
   - Шрифт: `.font-mono`
   - Размер: `text-[11px] md:text-xs`
   - Прозрачность: `text-foreground/60`
   - Ширина: `max-w-lg`

5. **Иконка-кнопка** (правый нижний угол)
   - Круглая кнопка с стрелкой вправо
   - Позиция: `fixed bottom-8 right-8 md:bottom-12 md:right-12`
   - Размер: `w-12 h-12 md:w-14 md:h-14`
   - Цвет: `bg-foreground` (черный фон)
   - Иконка: белая стрелка (используй lucide-react `ArrowRight`)

### Композиция и spacing

**КРИТИЧНО**: Следуй пропорциям референса!

- **Между виджетом и заголовком**: `mb-8 md:mb-12` (НЕ больше!)
- **Между заголовком и текстом**: `mb-6 md:mb-8` (БЛИЗКО!)
- **Padding секции**: `px-8 md:px-16 pt-24`
- **Отступ Header**: `py-6 md:py-8`

## 📝 Правила работы для Antigravity

### 1. Коммуникация

- ✅ **Объясняй решения**: Пиши комментарии на русском для сложной логики
- ✅ **Технический стиль**: Чётко и по существу
- ✅ **Предупреждай**: Если что-то может не работать - скажи заранее
- ✅ **Альтернативы**: Предложи несколько вариантов если есть выбор

### 2. Качество кода

- ✅ **TypeScript strict**: Никаких `any`, используй интерфейсы
- ✅ **Компонентный подход**: Маленькие, переиспользуемые компоненты
- ✅ **DRY**: Не дублируй логику
- ✅ **KISS**: Простые решения лучше сложных
- ✅ **Именование**: Понятное, описательное (не сокращения)

### 3. Стиль кода

```tsx

      </div>
    </section>
  );
}

// ❌ ПЛОХО

  // всё в одном файле, 500 строк...

}
```

### 4. Tailwind CSS

- ✅ Используй утилиты Tailwind, не пиши кастомный CSS
- ✅ Используй переменные цветов: `bg-background`, `text-foreground`
- ✅ Адаптивность: `md:`, `lg:` префиксы
- ✅ Кастомные утилиты доступны: `.transition-smooth`, `.container-custom`
